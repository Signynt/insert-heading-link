# Insert Heading Link

Adds a command to insert a link to a heading, like `[[##]]`. Assign a hotkey for it in Obsidian if you want one.

![Example](https://github.com/Signynt/insert-heading-link/blob/master/resources/gifs/insert-heading-link-example.gif)

## Installation
Install the plugin from the Obsidian community plugins browser, and enable it.

## Usage
1. Place the cursor where you want to insert the heading link.
2. Run the "Insert Heading Link" command from the command palette, or use the assigned hotkey.
 
A link to the nearest heading above the cursor will be inserted.
